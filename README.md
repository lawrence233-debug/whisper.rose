# Whisper Rose

A static storefront for the Whisper Rose product catalog, auth pages, and checkout flow.

## Local development

Open the site in a browser using a local web server, for example:

```bash
python -m http.server 8080
```

Then visit:

- http://localhost:8080/comerence.html

## Deploy to Render

1. Push this project to a GitHub repository.
2. Log in to Render.
3. Click New > Static Site.
4. Connect the GitHub repository.
5. Set the publish directory to `.`
6. Deploy.

> This is a static site, so no backend build step is required.
